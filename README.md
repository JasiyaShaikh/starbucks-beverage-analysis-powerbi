☕ Starbucks Beverage Analysis Dashboard
📊 Project Overview

This project is an interactive Starbucks Beverage Analysis Dashboard developed using Microsoft Power BI.

The dashboard transforms beverage and nutritional data into meaningful visual insights using KPIs, charts, filters, and interactive analysis.

The main objective of this project is to explore beverage categories and compare nutritional attributes such as calories, sugar, and caffeine through an easy-to-understand dashboard.

🎯 Project Objectives
Analyze Starbucks beverage categories
Compare nutritional characteristics of beverages
Analyze average calories across beverage categories
Identify beverages with high caffeine content
Understand beverage category distribution
Create an interactive and visually engaging dashboard
Practice data visualization and data storytelling
📌 Dashboard Overview

The dashboard contains the following key metrics:

KPI	Description
Total Beverages	Total number of beverages analyzed
Average Sugar	Average sugar content of beverages
Average Calories	Average calorie content
Average Caffeine	Average caffeine content
📈 Visualizations

The dashboard includes:

Average Calories by Beverage Category
Starbucks Global Presence
Beverage Category Distribution
Average Caffeine by Category
Top 5 Highest Caffeine Beverages
🎛️ Interactive Filters

Users can explore the dashboard using:

Beverage Category
🛠️ Tools & Technologies
